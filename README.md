# Alumni Network Platform

A modern, responsive and interactive Alumni Network Platform developed as a free web development internship project.

The platform is designed to connect alumni, students and professionals through an organized digital community where users can discover alumni, attend events, explore career opportunities, find mentors and support fundraising campaigns.

## Project Overview

The Alumni Network Platform is a frontend web application created to provide a centralized platform for alumni networking and community engagement.

The platform allows users to:

- Discover and search alumni
- Filter alumni by batch, location and profession
- Explore upcoming events
- RSVP for events
- Browse job and internship opportunities
- Apply for jobs
- Connect with mentors
- Support fundraising campaigns
- Manage alumni profiles
- View community news
- Explore alumni success stories
- Browse a photo gallery
- Access an admin dashboard
- Register and log in
- Switch between light and dark mode

## Main Modules

### 1. Home / Landing Page

The homepage contains:

- Hero section
- Community introduction
- Alumni statistics
- Feature cards
- Alumni success stories
- Call-to-action section

---

### 2. Alumni Directory

The Alumni Directory allows users to find alumni using:

- Name
- Profession
- Company
- Batch
- Location
- Profession

Search and filtering are implemented using JavaScript.

---

### 3. Events Management

The Events module provides:

- Upcoming events
- Event dates
- Event locations
- Event categories
- Attendee information
- RSVP functionality
- Create Event functionality

---

### 4. Job Board

The Job Board provides career opportunities posted by the alumni community.

Features include:

- Job title
- Company
- Location
- Employment type
- Experience
- Apply functionality
- Post Job functionality

---

### 5. Mentorship Program

The Mentorship module connects students and professionals with experienced alumni.

Users can view:

- Mentor name
- Profession
- Company
- Experience

Users can also send a simulated mentorship request.

---

### 6. Fundraising

The Fundraising module allows users to explore community campaigns.

Each campaign includes:

- Campaign title
- Description
- Campaign image
- Fundraising goal
- Amount raised
- Progress bar
- Donation functionality

The donation system is simulated using JavaScript.

---

### 7. Alumni Profile

The profile module allows users to:

- View profile information
- Edit profile information
- Update their name
- Save profile changes

Profile information is stored using LocalStorage.

---

### 8. Admin Dashboard

The Admin Dashboard provides an overview of:

- Total alumni
- Events
- Job posts
- Donations
- Recent registrations
- Quick administrative actions

---

## Bonus Features

The project also implements additional features beyond the core requirements.

### Alumni Success Stories

Displays inspirational stories from alumni.

### Photo Gallery

A responsive gallery showcasing community and networking activities.

### News & Announcements

Displays important updates and announcements for the alumni community.

### Dark Mode

Users can switch between light mode and dark mode.

The selected theme is remembered using LocalStorage.

### Simulated Notifications

The website provides toast notifications for actions such as:

- Successful login
- Registration
- RSVP
- Job application
- Mentorship request
- Donations
- Profile updates

### Downloadable Report

The Admin Dashboard includes an option to download a basic project/activity report.
